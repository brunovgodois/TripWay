## Páginas do site

- **Home** (`index.html`): página inicial do TripWay, com apresentação, cards e seção sobre a empresa.
- **Destinos** (`destinos.html`): Rio de Janeiro, Lençóis Maranhenses e Fernando de Noronha, organizados em cards.
- **Pacotes** (`pacotes.html`): pacotes e serviços para cada destino, com imagens, descrições e botões para contato.
- **Contato / Reserva** (`contato.html`): formulário para solicitar uma reserva.

## Evolução do CP1 para o CP2

**CP1:** criação do site com quatro páginas em HTML semântico, navegação entre as páginas e um formulário de contato básico, sem estilização.

**CP2:** o grupo dividiu o trabalho em arquivos diferentes, cada integrante com duas novas entregas:

- **Gustavo Policarpo**
  - Criação do CSS completo, com cores, fontes, menu, cards, formulário e responsividade.
  - Atualização da Home (`index.html`), conectando o CSS e organizando a apresentação, os cards e a seção sobre a empresa.
- **Bruno Godois**
  - Atualização de `destinos.html`, corrigindo a estrutura e organizando os três destinos em cards.
  - Atualização de `pacotes.html`, organizando imagens, descrições e botões para contato.
- **Samuel Ribeiro**
  - Atualização de `contato.html`, com campos reorganizados em grupos (dados pessoais e dados da viagem), classes em todos os elementos do formulário, opções de destino iguais às do site e validação com atributos HTML (`required`, `minlength`, `maxlength`, `min` e `max`).
  - Atualização deste `README.md`.

## Como abrir o projeto

1. No GitHub, abra o repositório e clique no botão verde **Code**.
2. Baixe o projeto em **Download ZIP** e extraia a pasta, ou copie o link e rode `git clone` com ele no terminal.
3. Abra a pasta do projeto.
4. Dê dois cliques no arquivo `index.html` para abrir a página inicial no navegador. Se preferir, abra a pasta no VS Code e use a extensão **Live Server**.
5. Use o menu de navegação para acessar as páginas Destinos, Pacotes e Contato.
